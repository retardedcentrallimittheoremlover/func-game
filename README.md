# Shoot'em Up

## Launching the game
run the following commands in the terminal:
```
cabal build
cabal run
```

## Playing the game
### Main menu controls
- Press `1` `2` or `3` to start a game at the corresponding difficulty level.
### In-game controls
- Press the up/down arrow keys to move the player ship.
- Press the space bar to shoot bullets.
- Press `p` to pause the game.
- Press `m` to return to the main menu.
### Objectives
- Shoot the enemies to gain points.
- Avoid the enemies and their bullets to prevent losing the game.
